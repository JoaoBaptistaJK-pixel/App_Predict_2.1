# 📦 Predict - Monitoramento de Estoque

## 📋 Sobre o Projeto
O **Predict** é um aplicativo de monitoramento e controle de estoque, desenvolvido especificamente para gerenciar produtos com data de validade. Seu objetivo principal é auxiliar donos de supermercados e comerciantes a evitar o desperdício e o prejuízo financeiro, facilitando o acompanhamento de itens que estão próximos do vencimento de forma rápida, centralizada e visual.

## 🛠️ Tecnologias Utilizadas
* Linguagem principal: Kotlin/Java
* IDE: Android Studio
* Gerenciamento de Estado: Navegação nativa e armazenamento em memória/local

## 🚀 Como rodar o projeto
1. **Pré-requisitos:** Tenha o [Android Studio](https://developer.android.com/studio) instalado na sua máquina.
2. [**Clone o repositório:**]
   Abra o terminal e rode o comando:
   git clone https://github.com/JoaoBaptistaJK-pixel/App_Predict_2.1
3. **Abra no Android Studio:**
   * Abra o Android Studio e clique em **File > Open**.
   * Selecione a pasta clonada do projeto.
   * **Importante:** Não use a opção "Import Project".
4. **Sincronização:** Aguarde o *Gradle Sync* finalizar automaticamente para baixar as dependências corretas.
5. **Execução:** Conecte um dispositivo físico via USB ou inicie um Emulador (AVD) e clique no botão verde de **Run (Shift + F10)**.
